# 퀴즈메이트 (QuizMate)

> 수업 자료만 넣으면 AI가 시험지를 만들고, 채점과 오답노트까지 챙겨 주는 학습 웹사이트

기초웹 프로그래밍 프로젝트 · 2500077 박지윤

- 시연 영상: [YouTube](https://youtu.be/Y4KwSbRvf_0) · [docs/demo.mp4](docs/demo.mp4)

## 주요 기능

| 페이지 | 기능 |
|---|---|
| 대시보드 | 푼 문제 수, 정답률, 남은 오답, 최근 점수 그래프 |
| 새 문제 만들기 | 글 붙여넣기, PDF·TXT·사진 업로드 → 문제 수·난이도·유형(객관식, O/X, 단답형, 서술형) 선택 → AI 문제 생성 |
| 문제 풀이 | 한 문제씩 풀이, 진행률 표시, 키보드로 선택 |
| 채점 결과 | 즉시 채점, 해설과 자료 근거 문장, 서술형은 AI 점수와 피드백 |
| 오답노트 | 틀린 문제 자동 저장, 메모, 다시 풀기, 비슷한 문제 만들기, 두 번 연속 맞히면 완료 |
| 문제 세트 | 만든 시험지 목록, 다시 풀기, 삭제 |
| 내 데이터 | 저장 위치와 데이터 구조 안내, 백업 파일 내려받기·불러오기, 전체 삭제 |

## 실행 방법

### 1. 실제 서비스 (AI 기능 포함)
claude.ai에 공개한 페이지에서 Claude 계정으로 로그인해 사용합니다. 문제 생성과 채점은 사용자의 Claude 계정으로 동작하고, 기록은 사용자별 개인 저장 공간에 저장됩니다.

### 2. 내 컴퓨터에서 열기 (화면 확인·수정용)
1. VS Code에서 이 폴더를 엽니다.
2. `index.html`을 **Live Server**로 실행합니다.
3. 예시 문제 세트(광합성)로 풀이, 채점, 오답노트를 확인할 수 있습니다.

> 내 컴퓨터에서는 Claude에 연결되지 않으므로 **AI 문제 생성과 AI 채점은 동작하지 않습니다.** 서술형은 핵심어 일치도로 간이 채점하고, 기록은 이 브라우저(localStorage)에만 저장됩니다.

## 수업에서 배운 개념 적용 (기초웹 프로그래밍 1~4장)

| 장 | 적용한 곳 |
|---|---|
| 1장 웹의 원리 | HTML(구조)·CSS(디자인)·JavaScript(동작) 역할 분리, URL의 문서 안 위치(`#home`, `#new`, `#notes`, `#data`)로 화면 전환, 브라우저가 AI에 요청하고 응답으로 문제를 받음 |
| 2장 문서 구조 | `<!DOCTYPE html>`, `<html lang="ko">`, `<meta charset="utf-8">`, `<title>`, `header`·`nav`·`main`·`footer` 영역 구분, 사용자 입력을 문자 참조(`&lt;` 등)로 바꿔 표시 |
| 3장 목록·링크 | 순서가 중요한 문제별 채점 결과는 `<ol>`, 최근 기록·문제 세트는 `<ul>`, 메뉴는 `<a href="#notes">` |
| 4장 입력 폼 | `label`의 `for`와 입력 칸의 `id` 연결, `<input type="file" accept=".pdf,.txt">`, `<select>` 필터, `maxlength` 글자 수 제한 |

## 추가로 개발한 것

- **PDF 글자 추출:** pdf.js 라이브러리로 브라우저에서 PDF 글자를 뽑음. 사진은 AI가 글자를 읽음
- **AI 문제 생성:** 자료만 근거로 4가지 유형 문제와 해설, 근거 문장을 JSON으로 받아 검사 후 사용
- **AI 채점:** 단답형은 뜻이 같은지 비교, 서술형은 채점 기준으로 0~100점과 피드백
- **오답노트 로직:** 틀린 횟수, 연속 정답 수, 두 번 연속 정답 시 완료 처리
- **데이터 저장:** 사용자별 개인 경로(`data/users/<사용자 ID>/`)에 문제 세트(`set_`), 풀이 기록(`att_`), 오답(`wn_`) 세 종류의 문서로 저장, 백업(JSON)·불러오기·삭제
- **화면:** 반응형 레이아웃(휴대폰 하단 탭), 점수 원형 그래프와 최근 점수 그래프(SVG), 80점 이상 색종이 효과

## 개발 과정

1. **Bolt AI + Gemini + Supabase**로 시작했지만, 무료 플랜 토큰 한도로 채점·오답노트를 만들기 전에 개발이 멈췄고 AI 기능에 API 키 등록이 따로 필요했음
2. 개발 도구를 **Claude**로 바꿔, 기능 명세 프롬프트([docs/prompt.md](docs/prompt.md))를 바탕으로 대화하며 완성
3. 디자인 수정, 데이터 저장 방식 점검(‘내 데이터’ 화면 추가), 수업 PDF로 실제 시험
