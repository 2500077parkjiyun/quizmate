처음 Bolt AI에 전달했던 기능 명세입니다. 이후 Claude로 도구를 바꾼 뒤에도 이 명세를 바탕으로 개발했고, 기술 스택(Supabase, Gemini)은 Claude 환경에 맞게 바뀌었습니다.

```
학습 자료를 넣으면 AI가 문제를 만들어 주고, 사용자가 풀면 자동으로 채점하고, 틀린 문제는 오답노트에 저장해 주는 학습 웹사이트 "퀴즈메이트(QuizMate)"를 만들어줘.
모든 화면 텍스트는 한국어로 작성해줘.

## 기술 스택
- React + TypeScript + Vite + Tailwind CSS
- 아이콘: lucide-react
- 데이터베이스/로그인: Supabase (이메일 회원가입/로그인)
- AI 호출: Supabase Edge Function에서 Google Gemini API를 호출. API 키는 Edge Function의 환경변수 GEMINI_API_KEY로만 사용하고, 프론트엔드 코드에는 절대 넣지 마.
- PDF 텍스트 추출: pdfjs-dist (브라우저에서 추출)

## 페이지 구성
1. 로그인 / 회원가입 페이지
2. 대시보드 (총 푼 문제 수, 전체 정답률, 오답노트 남은 문제 수, 최근 문제 세트, "새 문제 만들기" 버튼)
3. 자료 입력 & 문제 생성 페이지
   - 입력: 텍스트 붙여넣기 / PDF 업로드 / TXT 업로드, 추출한 텍스트 미리보기·수정, 최대 약 15,000자
   - 옵션: 제목, 과목/태그, 문제 수(5/10/15/20), 난이도(쉬움/보통/어려움), 유형(객관식, O/X, 단답형, 서술형)
4. 문제 풀이 페이지 (한 문제씩, 진행 바, 이전/다음, 번호로 이동, 미응답 알림)
5. 채점 결과 페이지 (100점 환산, 유형별 정답률, 문제별 정답 여부·해설, 서술형 AI 부분 점수와 피드백, "틀린 문제만 다시 풀기")
6. 오답노트 페이지 (필터·정렬, 메모, 다시 풀기, 두 번 연속 맞히면 완료, 비슷한 문제 만들기)
7. 내 문제 세트 목록 페이지

## 채점 규칙
- 객관식, O/X: 정답과 비교해 즉시 채점
- 단답형: 공백·대소문자·띄어쓰기 무시 후 정답 또는 허용 답안과 비교, 다르면 AI가 의미가 같은지 판단
- 서술형: AI가 모범답안과 채점 기준으로 0~100점 채점 + 피드백

## AI 문제 생성 규칙
- 반드시 사용자가 제공한 자료 내용에 근거해서만 문제를 만들고, 자료에 없는 내용은 출제하지 않는다
- 각 문제에 자료의 어느 부분에 근거했는지 짧게 표시한다(source_quote)
- 객관식 오답 선택지는 그럴듯하지만 명확히 틀린 것으로 만든다
- 해설은 왜 정답인지 + 왜 다른 선택지가 틀렸는지를 2~4문장으로 쓴다
- 응답은 정해진 JSON 형식만 출력한다
```

## 2단계: 대화로 다듬기 (Claude)

1. 명세를 바탕으로 사이트 완성 (API 키 없이 사용자의 Claude 계정으로 AI 연결)
2. "디자인 좀 예쁘게" → "진짜 웹사이트처럼 밝고 컬러풀하게"
3. 데이터 저장 방식 점검 → ‘내 데이터’ 화면(저장 위치, 데이터 구조, 백업·삭제) 추가
4. 수업 PDF로 실제 시험
